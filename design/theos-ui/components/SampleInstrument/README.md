Sample screen in the Instrument register (Review preset): rail, title bar, toolbar, viewport, console, the hot review window and the inspector, built only from system classes.

It exists to prove the register, not to propose a layout: dense mono data, uppercase chrome, square corners, colour only for meaning. Amber appears where a human must act (the pending entries, the active preset, the primary action); magenta only next to the AI marker.

The viewport carries `data-theme="grid-noir"`: in Grid Light everything around it turns light while the 3D stage stays dark.
