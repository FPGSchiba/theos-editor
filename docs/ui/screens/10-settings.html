Author name Used for every commit you make. git.author.name user
Author email Empty means: take it from your git config. git.author.email user
Committing
Commit on every save Off: Ctrl+S only writes the file and you commit from Changes. git.commit_on_save off project
Suggest commit messages Suggestions show in magenta with an AI mark until you edit them. git.suggest_messages on project
Order rules before commit Reveal order, requires and three-clue. Never-confirm, no-overshoot and in-world words always block and have no setting. git.validate project
