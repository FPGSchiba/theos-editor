# editor-ui

The web UI of the Theos editor: Svelte 5 (runes), TypeScript (strict), Vite, pnpm. The Tauri app
in `crates/theos-editor` loads it from the dev server (`http://localhost:5179`) or from `dist/`.
Spec: `docs/specs/phases/P11-editor-shell-and-codex.md` §5.5–§5.7, §5.12.

## Setup

Node 24 and pnpm 12.23.0 (the `packageManager` pin; Corepack picks it up). Versions in
`package.json` are exact; `pnpm-workspace.yaml` keeps every version, transitive ones included, at
least two weeks old.

```text
pnpm install --frozen-lockfile
pnpm exec playwright install chromium   # once, for the page tests
```

## Commands

| Command | What it does |
|---|---|
| `pnpm dev` | Dev server on port 5179 (strict), the one the app loads |
| `pnpm app [<project>]` | The dev server and the app (`scripts/app.js`); a relative path is taken from where you typed the command |
| `pnpm build` / `pnpm preview` | Build to `dist/` / serve it |
| `pnpm check` / `pnpm lint` / `pnpm test` / `pnpm e2e` | svelte-check, ESLint, Vitest, Playwright |

Opening a project writes its index cache, so open a copy of a fixture, as the crate's README
(`crates/theos-editor/README.md`) does. From the repository root, copy it into the ignored
`target/` (in PowerShell: `Copy-Item -Recurse`) and start both:

```text
cp -r crates/theos-studio/tests/fixtures/projects/editor-codex target/editor-codex
pnpm --dir editor-ui app target/editor-codex
```

Without `scripts/app.js`, run `pnpm dev` and `cargo run -p theos-editor -- <project>` in two
terminals. Closing the window stops both. Ctrl+C (or SIGTERM, SIGHUP, any exit of the script)
stops the app as a whole process tree (`scripts/stop-tree.js`: `taskkill /T /F` on Windows,
SIGTERM to the child's process group elsewhere), so no cargo, app or WebView process is left
behind.

The gate's `ui` check (`docs/gate.md`) runs, in this folder:

```text
pnpm install --frozen-lockfile
pnpm exec svelte-check --fail-on-warnings
pnpm exec eslint .
pnpm exec vitest run
pnpm exec playwright test
```

## Rules the checks hold

- **Generated IPC.** `src/lib/ipc/bindings.ts` is generated by tauri-specta from Rust
  (`UPDATE_BINDINGS=1 cargo test -p theos-editor bindings`); never edit it. Screens call
  `call(commands.<name>(…))` from `src/lib/ipc/client.ts`. ESLint forbids importing `invoke`
  outside `src/lib/ipc/`.
- **No `{@html}`** (ESLint `svelte/no-at-html-tags`).
- **Tokens only.** Theos UI comes from `design/theos-ui/` by relative import (`src/main.ts`).
  Components use `var(--…)` tokens and `tu-*` classes; `tests/styles.test.ts` fails on colour
  literals, font families that are not tokens, `opacity` and px font sizes.

## Page tests

`e2e/*.spec.ts` run in Chromium against `vite preview` of a fresh build (port 4179). They answer
IPC from the recordings in `e2e/ipc/`, which a Rust test writes from real answers:

```ts
const ipc = await replay(page, { os: 'windows', use: ['codex_tree-who-empty'] });
await page.goto('/');
```

A call is answered by the recording with the same `cmd` and deep-equal `args`; `app_info` by
`app_info-<os>`. When only one recording has the call, it answers, whatever its keys. When several
share it, the one named in `use` answers (later names win, also through `ipc.use(…)` during a
test), else the only one with neither a `derived` key nor a `fixture` key (a recording on another
fixture project, such as `duplicate-id`). A call no recording answers, or an ambiguous one, fails
the test with its cmd and args.

- `fail: { <cmd>: <error> }` makes a command reject with that error.
- `answer: { <cmd>: <value> }` answers a plugin's command, which no recording can hold, such as
  the folder dialog's `plugin:dialog|open`.
- Events are mocked in the page: `await ipc.emit('tauri://focus')` sends the window's focus to the
  app, as in `e2e/freshness.spec.ts`.

The recordings and `src/lib/ipc/bindings.ts` are written by Rust tests; after a change of a command
or a fixture run `UPDATE_BINDINGS=1 cargo test -p theos-editor --test bindings --test recordings`
(see `crates/theos-editor/README.md`).
