# Probes of `theos_maps` 0.3.0 (map research, stage 4)

> **Caveat (applies to every result):** theos_maps 0.3.0 has no sediment deposition and no
> multiple-flow routing (the planned Rust generator adds both). A probe shows what the
> architecture and recipe model can express, not what the new generator's maps will look like.

Report: `../05-probes.md`. This folder holds text only (no images, no packages).

| Path | What |
|---|---|
| `toolset/` | Unchanged copy of `Design/_system/tools/` (13 `theos_maps/*.py`, README, CHANGELOG, requirements), `recipes/` (3 shipped recipes), `map-stages/` (`omega_detuning.py`), `refs/` (the map skill's `recipes.md`, `extending.md`). Staged from the user's Drive on 2026-11-11. |
| `recipes/` | Probe recipes `p1a` … `p7b`; `p8-blend/` is generated by `scripts/blend.py`. |
| `ext/bore_grid.py` | Probe-only extension: stage `grid_bore` (fixed base-level cells inside the map) and `bore_check`. Not part of the toolset. |
| `scripts/probe.py` | Driver: runs a recipe per seed, adds probe metrics (slope distribution, tower count, storeys, street grid index), writes results JSON and a contact sheet with the caveat banner. |
| `scripts/blend.py` | Probe 8: interpolates all numeric values between two recipes and compares successive maps. |
| `scripts/summarise.py` | Compact one-line-per-seed view of results files. |
| `results/` | `<recipe>_results.json` per probe (summary, constraints, probe metrics, run time per seed). |

## Versions used

Ubuntu 24.04.5 (x86_64, 2 cores), Python 3.12.3 in a `uv` 0.11.32 venv.
`fastscapelib 0.3.0` (PyPI wheel), `numpy 2.5.4`, `scipy 1.18.1`, `matplotlib 3.11.2`, `networkx 3.7`,
`scikit-image 0.26.0`, `PyYAML 6.0.3`, `pillow 13.0.0`. The toolset's `requirements.txt` pins only
`fastscapelib==0.3.0`; the rest are lower bounds.

## Reproduce

```bash
cd research/map-generation/probes
uv venv --python 3.12 ../.venv
uv pip install --python ../.venv/bin/python -r toolset/requirements.txt
export MPLBACKEND=Agg PYTHONPATH=toolset PY=../.venv/bin/python O=<scratch dir> S=<sheet dir>

# baseline (the toolset's own CLI)
(cd toolset && $PY -m theos_maps.run recipes/hearth-valley.yaml   $O/baseline --seeds 1)
(cd toolset && $PY -m theos_maps.run recipes/choir-hall-ruin.yaml $O/baseline --seeds 1)

# terrain and interior probes: seeds 1-4, one contact sheet each
for r in p1a-small-valley-4km p1b-farmland-16km p3-wildwood-16km p5-needle-peaks-8km \
         p5x-needle-peaks-n2-8km p7a-rim-east-12km p4a-underdeep-max p4b-cavern; do
  $PY scripts/probe.py recipes/$r.yaml $O/$r --sheet $S/${r}_contact.png
done
$PY scripts/probe.py recipes/p4c-underdeep-scale-500.yaml $O/p4c --seeds 1 --sheet $S/p4c-underdeep-scale-500_contact.png --cols 1 --tile 1100
$PY scripts/probe.py recipes/p7b-bore-centre-12km.yaml $O/p7b --ext ext --sheet $S/p7b-bore-centre-12km_contact.png

# probe 2 and 6: the region must be exported first, the detail maps read its engine package
$PY scripts/probe.py recipes/p2-rune-region-12km.yaml $O/p2 --export --sheet $S/p2-rune-region-12km_contact.png
$PY scripts/probe.py recipes/p2-walled-town-detail.yaml $O/p2d \
    --parent-template "$O/p2/p2-rune-region-12km_s{seed}_engine" --sheet $S/p2-walled-town-detail_contact.png
$PY scripts/probe.py recipes/p6-city-size-4km.yaml $O/p6 --seeds 1 2 \
    --parent-template "$O/p2/p2-rune-region-12km_s{seed}_engine" --sheet $S/p6-city-size-4km_contact.png --tile 800   # ~4.5 min per seed

# probe 8
$PY scripts/blend.py recipes/p1b-farmland-16km.yaml recipes/p3-wildwood-16km.yaml $O/p8 \
    --steps 5 --seeds 1 2 --sheet-prefix $S/p8-blend-band1-to-band3
```

Notes:

- A detail recipe's seed here is the region seed (the toolset's own `details.py` derives a child seed
  from the region seed and the feature id instead).
- `p3-wildwood-16km.yaml` is the tuned version. The first version (orogen 2.8e-3 m/yr) gave 2.9-4.2 km
  relief; its numbers are kept in `results/p3-wildwood-16km_first-untuned_results.json`.
- `p6` seeds 1 and 2 were run in separate invocations; the sheet was tiled from both.
- Run time: about 17-20 s per terrain seed at 384 x 384, 1-9 s per interior seed, 9-11 s per
  default city detail, about 255 s per 800 x 800 city detail.
